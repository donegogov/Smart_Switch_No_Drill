clone this repo on raspberry pi zero
connect motion detector on gpio 17
connect standart servo on gpio 18
connect gnd and vcc from motion detector and servo
start servo.py - it will start server on address 0.0.0.0:50100
open your router see raspberry pi ip address
type in browser http://ip_rpi:50100 replace rpi with raspberry pi ip address
now you can on or off switch and on or off motion detector mode
