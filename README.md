1. clone this repo on raspberry pi zero
2. connect motion detector on gpio 17
3. connect standart servo on gpio 18
4. connect gnd and vcc from motion detector and servo
5. start servo.py - it will start server on address 0.0.0.0:50100
6. open your router see raspberry pi ip address
7. type in browser http://ip_rpi:50100 replace rpi with raspberry pi ip address
8. now you can on or off switch and on or off motion detector mode
